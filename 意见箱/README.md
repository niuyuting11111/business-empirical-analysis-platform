# 意见箱使用说明

这是一个收集意见、问题、改进建议的汇总箱。任何人在使用「实证派」平台时遇到的问题或想法，都可以放进这里，之后让 AI 助手统一读取并处理。

## 提交意见的两种方式

**方式一（推荐）：平台内表单提交，零门槛**

打开「实证派」平台，侧边栏最下方选「📮 意见反馈（问题/建议）」，填好称呼、标题、描述后点「提交反馈」即可。系统会自动按模板生成一条 `.md` 记录存进 `收件箱/`，不需要碰任何文件。

**方式二：手写 markdown（适合不方便打开平台的情况）**

复制 `_模板_意见模板.md`，改个好认的文件名（比如 `2026-08-27_张三_导出乱码.md`），填好内容后放进 `收件箱/` 即可。关键是写清楚两点：**发生了什么**、**期望变成什么样**。有截图或数据样例更好。

## 目录结构

- `收件箱/`：新的意见、问题（每条一个 `.md` 文件，表单提交会自动生成）。
- `已处理/`：AI 助手处理完的条目会自动移到这里，并在条目里附上处理结果说明。
- `_模板_意见模板.md`：手写条目时可以直接复制这份模板填写。

## 你（主人）：怎么让 AI 处理

只要对 AI 助手说一句，例如：

- 「读一下意见箱」
- 「处理意见箱里的反馈」
- 「看看收件箱有没有新问题，直接改」

AI 助手会自动：

1. 读取 `收件箱/` 里的全部条目；
2. 逐条判断是"能直接改代码解决的"还是"需要答复/讨论的"；
3. 对能改的，直接修改 `app.py`（或相关文件）并验证；
4. 在每条意见里补上「处理结果」，然后把文件移动到 `已处理/`；
5. 最后给你一份汇总：改了哪些、答复了哪些、哪些需要你拍板。

## 说明

- 平台代码在版本控制（git）里，改动可随时回退，放心让 AI 直接改。
- 涉及大方向、有风险或需要你决策的改动，AI 会先列出来征求你的意见，不会擅自大改。
- 想一次性清空已处理记录，直接删 `已处理/` 里的文件即可。
